## Download

1. Download **`AudioMe-1.2.0.0-win-x64.zip`** below (under *Assets*).
2. Right-click the zip → **Extract All**, then open the folder and run **`AudioMe.exe`**. No installer or admin rights needed.
3. If Windows shows *"Windows protected your PC"*, choose **More info → Run anyway**. The app isn't code-signed yet; the `.sha256` file lets you verify the download.

Requires Windows 10/11 x64 with .NET Framework 4.8 (built into Windows 11). Audio Me lives in the tray: left-click the icon for quick switching, right-click for profiles and Exit.
